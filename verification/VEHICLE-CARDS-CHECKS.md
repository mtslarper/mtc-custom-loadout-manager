# Проверка карточек техники — 23 октября 2026

Источник игровых данных: https://multicrew.wiki/. Использованы публичные ответы каталога для MTC и Rainy Valley, включая отдельные публичные страницы скрытой техники. Файлы приватного плейса Roblox не извлекались.

- Исходный список редактора: 384 игровых ID. Данные найдены для 383; изображения — для 333. Всего сохранены 343 файла WebP, включая варианты названий MTC/RV и текущие ID для импортируемых машин.
- Для старого `GTK Boxer` точного соответствия нет. Для 51 исходного ID изображения недоступны в официальном каталоге. Полные списки находятся в `vehicle-info-report.json`.
- `node tools/check-vehicle-info.mjs`: успешно. Проверены соответствия ID исходным данным, числовые параметры, описания, заголовки всех используемых WebP и наличие патчей.
- Базовый IS-3: 40 км/ч, 48 т, 4 места, основное орудие 122mm D-25T. Базовая масса M1A2 SEP V3 — 66,8 т, без подмены массой дополнительного TUSK.
- HTTP: успешно получены 346 ресурсов — JS, CSS, каталог JSON и 343 изображения. Для изображений сервер возвращает `image/webp`.
- Повторное применение `tools/patch-import.mjs` дважды не меняет хэши HTML и страницы; импорт из файла, множественное выделение и карточки сохраняются.
- Синтаксис сервера, новых скриптов, патчей и изменённой браузерной сборки проверен Node.js.
- В браузере проверены карточки IS-3 и BT-5 в списке, BMP-3 (2017) в колонке команды с правильным текущим тиром, переключение MTC/RV, выбор эпохи Cold War и закрытие по Esc.
- В браузере проверены реальная загрузка локального изображения IS-3 и отсутствие карточек у оружия. Для AFV-16 первоначально проверены доступные ТТХ и описание.
- Открытие карточек в браузере проверялось клавиатурным фокусом; обработчики мыши подключены через pointerover/pointerout с задержкой 320 мс и возможностью перевести курсор на карточку.
- Ошибок и предупреждений JavaScript в проверенном сеансе браузера не обнаружено.

## Просмотр модификаций

- Дополнительное оснащение или версии по эпохам найдены для 158 машин исходного списка (с учётом MTC/RV).
- Проверено, что в каталог попали все названия и стоимости из исходных `alterations.addons`, а также все изменения по эпохам из `alterations.loadouts`.
- На M1A2 SEP V3 в браузере проверены вкладка «Модификации (4)», раскрытие Trophy APS + TUSK, цена 750, масса 66,8 → 72,7 т и система Trophy. Возврат в «Обзор» сохраняет базовую массу 66,8 т.
- M829A4: показана замена M829A3 на M829A4 без приписывания изменений остальным снарядам. Переключение MTC/RV обновляет список модификаций выбранной версии игры.
- BMP-3 (2017), Floaters: показаны цена 50, эпоха Modern и пояснение по названию с явной пометкой об отсутствии подробной выгрузки.
- IS-3, Cold War: показана замена BR-471B на BR-471D. BT-5: отображается сообщение об отсутствии опубликованных модификаций.
- Каталог и описания пересобираются из сохранённых ответов через `node tools/sync-vehicle-info.mjs --offline`, без сетевых запросов.
- Просмотр не изменяет игровые JSON или сохранённое оснащение. Проверки каталога и синтаксиса проходят; ошибок и предупреждений браузера не обнаружено.

Проверка проводилась в отдельном браузерном сеансе на `127.0.0.1:4173`. Для проверки импортирован встроенный Modern (MTC); пользовательские сохранения по адресу `localhost:4173` не затрагивались.
