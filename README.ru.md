# MTC Custom Loadout Manager

[English](README.md) | **Русский**

Кнопка **EN / RU** сразу после **Manage / Управление** переключает язык редактора, карточек техники и пояснений модификаций. По умолчанию выбран английский; выбор сохраняется в браузере. Переключение не сбрасывает текущий набор и не меняет экспортируемый JSON. Исходные описания из игры/вики и названия техники сохраняются на языке источника.

Локальный редактор пользовательских loadout-конфигураций для **Multicrew Tank Combat (MTC)** и **Rainy Valley (RV)** в Roblox. Распределяйте технику и оружие по командам и тирам, настраивайте лимиты, сохраняйте наборы и экспортируйте игровые JSON-файлы.

После скачивания работает без интернета. Вход в Roblox, токены и доступ к частному серверу для запуска не нужны.

Проект основан на опубликованной браузерной сборке [Loadout Editor](https://loadout-editor.multicrew.dev/), дополненной локальным сервером, импортом файлов, групповым копированием и справочными карточками техники. Это самостоятельная модификация локальной копии, не официальный релиз разработчиков MTC.

## Возможности

- Редактирование техники и оружия на вкладках **Vehicles** и **Weapons**.
- Командные колонки, общий список **Shared**, тиры и числовые лимиты.
- Шесть встроенных пресетов: Modern, Cold War и WW2 для MTC и RV.
- Импорт JSON-файлов, сохранение наборов в браузере, экспорт и ссылки для обмена.
- Выделение нескольких предметов через **Shift + ЛКМ** и копирование перетаскиванием.
- Карточки при наведении: изображение, игровые ТТХ, вооружение и доступное описание.
- Просмотр модификаций: стоимость, эпоха, пояснение и опубликованные изменения характеристик.

## Требования

- **Node.js 20 или новее** — [официальный сайт Node.js](https://nodejs.org/).
- Современный браузер с поддержкой `DecompressionStream` для открытия ссылок обмена.

Все файлы приложения уже включены в репозиторий. Выполнять `npm install` и собирать Next.js не требуется.

## Быстрый запуск

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив либо клонируйте его через Git.
2. Откройте папку, содержащую `package.json`, `server.mjs` и `Start.cmd`.
3. Запустите приложение одним из способов ниже.

### Windows

Дважды нажмите **`Start.cmd`**. Скрипт проверит наличие Node.js, откроет браузер и запустит локальный сервер.

Если браузер открылся раньше сервера, обновите страницу после появления адреса в окне запуска.

### Через терминал — Windows, Linux и macOS

Откройте терминал в папке проекта и выполните:

```sh
npm start
```

Или запустите сервер напрямую:

```sh
node server.mjs
```

Откройте **[http://localhost:4173](http://localhost:4173)**. Оставьте окно терминала открытым на время работы. Для остановки сервера нажмите **Ctrl+C**.

Открывать `public/index.html` двойным щелчком не нужно: приложение использует локальный HTTP-сервер.

## Как пользоваться

### Загрузка исходного пресета

1. Откройте вкладку **Manage**.
2. Нажмите **Select** рядом с нужным пресетом.
3. Нажмите **Import loadout**.
4. Перейдите в **Vehicles** или **Weapons** и отредактируйте набор.

### Редактирование и копирование

Перетаскивайте предметы из правого списка в нужную ячейку команды и тира. Нажмите предмет в колонке, чтобы открыть его настройки.

Для группового копирования:

1. Удерживая **Shift**, выделите предметы в колонках — появится оранжевая рамка.
2. Перетащите один из выделенных предметов в нужную ячейку.
3. Предметы скопируются; оригиналы останутся в исходных ячейках.

Повторный **Shift + ЛКМ** снимает выделение предмета, **Esc** снимает всё выделение. Совпадающий предмет в целевой ячейке заменяется. Перетаскивание между тирами одной ячейки переносит предмет. Без группового выделения перетаскивание работает как обычный перенос.

### Импорт своего JSON

В **Manage** нажмите **Import from file** и выберите один или несколько файлов. Поддерживаются:

- пресеты редактора с полями `columns` и `items`, в том числе `*.editor.json`;
- игровые экспорты с полями `WeaponClasses` и `Vehicles`.

Файлы появятся в списке сохранений. Нажмите **Select**, затем **Import loadout**, чтобы открыть выбранный набор. Для игрового экспорта команды, общие списки, тиры и числовые лимиты преобразуются в структуру редактора.

Ограничения импорта: **4 MiB на файл**, до **20 файлов за раз**, до **64 колонок** и **20 000 предметов** в наборе. Файлы с неправильной структурой отклоняются с сообщением об ошибке.

### Сохранение, экспорт и обмен

На вкладке **Manage** доступны:

| Действие | Результат |
| --- | --- |
| **Save as** | Сохраняет текущий набор под указанным именем в браузере. |
| **Download loadout JSON** | Скачивает игровую JSON-конфигурацию. |
| **Copy loadout JSON** | Копирует игровую конфигурацию в буфер обмена. |
| **Copy share link** | Создаёт ссылку с конфигурацией. |

Скачанный JSON можно снова открыть через **Import from file**. Применение конфигурации внутри Roblox выполняется отдельно средствами игры; редактор не подключается к серверу и не меняет его настройки.

**Сохранения находятся в localStorage браузера.** Используйте один и тот же браузер и адрес: `localhost:4173`, `127.0.0.1:4173` и другой порт имеют отдельные хранилища. Очистка данных сайта или смена браузерного профиля может удалить доступ к сохранениям. Для резервных копий скачивайте JSON.

Ссылка обмена из локальной копии содержит `localhost`. Получателю нужно запустить свою копию редактора и открыть ссылку на её адресе, сохранив часть `#share=…`. Не размещайте в публичном доступе ссылки с конфигурациями, которые не хотите раскрывать.

### Изображения, ТТХ и модификации

Наведите мышь на технику в правом списке или в колонке команды. Карточка открывается с небольшой задержкой; на неё можно перевести курсор и прокрутить содержимое. **Esc** закрывает карточку. Поддерживается также открытие при клавиатурном фокусе.

Кнопки **MTC / RV** переключают доступные версии данных. У некоторых машин есть выбор эпохи. Во вкладке **Модификации** нажмите название комплекта, чтобы раскрыть стоимость, пояснение и изменения.

ТТХ относятся к игровой базовой комплектации. Отсутствующие параметры не подставляются. Пояснения модификаций содержат пометку об источнике: описание из игры, изменения модулей или пояснение по названию. **Просмотр модификаций не применяет их к экспортируемому JSON.**

## Данные и ограничения

В каталоге редактора **384 записи техники и 58 записей оружия**. По состоянию на 24 октября 2026 года игровые данные доступны для **383 записей техники**, изображения — для **379**. Из них 46 недостающих миниатюр получены из MTC Dev Tank Spawner.

Игровые характеристики взяты из опубликованных данных [Multicrew Wiki](https://multicrew.wiki/). Данные и изображения хранятся локально; во время обычной работы редактор не запрашивает их у Roblox или вики. Автоматического обновления нет, поэтому значения могут отличаться от текущей версии игры.

Список отсутствующих изображений: [missing-vehicle-images.txt](verification/missing-vehicle-images.txt). Для старого ID `GTK Boxer` отсутствуют также игровые характеристики; вариант FLW 200 вместо него не подставляется.

Исходные React/TypeScript-файлы и полный список зависимостей оригинального приложения отсутствуют: в репозитории хранится готовая браузерная сборка и дополнительные скрипты.

## Команды для разработки и проверки

Все команды выполняются из папки проекта.

| Команда | Назначение |
| --- | --- |
| `npm start` | Запустить локальный сервер. |
| `npm test` | Проверить импорт, ссылки обмена, копирование и защиту сервера. |
| `npm run check:vehicles` | Проверить каталог, изображения и соответствие исходным данным. |
| `npm run scan:secrets` | Найти известные форматы токенов, ключей и буквальных паролей. |
| `npm run sync:vehicles -- --offline` | Пересобрать каталог из сохранённых данных без интернета. |
| `npm run sync:vehicles` | Обновить доступные данные и изображения из вики с использованием кэша. |
| `npm run sync:vehicles -- --refresh` | Заново запросить характеристики и изображения из вики. |
| `npm run patch` | Повторно применить изменения к сохранённой исходной сборке. |
| `npm run prepare:release` | Подготовить отдельную папку для публикации. |

Обновление из вики требует интернета. Проверенные миниатюры спавнера сохраняются по соответствиям из `config/vehicle-images.json`.

`prepare:release` создаёт папку `github-upload` рядом с проектом и манифест SHA-256. Существующую папку он не перезаписывает. Чтобы выбрать новый путь:

```sh
npm run prepare:release -- ../github-upload-next
```

Скрипт не создаёт удалённый репозиторий и ничего не загружает на GitHub. Локальные скриншоты, браузерные профили, сохранения пользователя и резервные файлы в пакет не включаются.

## Решение проблем

**`node` или `npm` не найдены.** Установите Node.js, затем заново откройте терминал. Проверьте установку командой `node --version`.

**Порт 4173 занят (`EADDRINUSE`).** Если редактор уже запущен, откройте существующий адрес. Для запуска на другом порту в PowerShell:

```powershell
$env:PORT = '4174'
node server.mjs
```

В Linux или macOS:

```sh
PORT=4174 node server.mjs
```

После этого откройте `http://localhost:4174`. Сохранения с прежнего порта автоматически не переносятся.

**Не отображается изображение или часть ТТХ.** Проверьте [список пропусков](verification/missing-vehicle-images.txt) и выполните `npm run check:vehicles`. Убедитесь, что папки `public/data` и `public/assets/vehicles` скопированы полностью.

**Не открывается ссылка обмена.** Проверьте адрес и порт своей копии, целостность части `#share=…` и поддержку `DecompressionStream` браузером. Для обмена можно также передать JSON-файл.

**После обновления виден старый интерфейс.** Обновите страницу с очисткой кэша: **Ctrl+F5** в Windows/Linux или **Cmd+Shift+R** в macOS.

## Безопасность и права

Сервер по умолчанию доступен только на этом компьютере (`127.0.0.1`). Импорт проверяет структуру и размер файлов; добавлены ограничения распаковки ссылок и защитные HTTP-заголовки. Результаты и границы проверки сторонней сборки описаны в [SECURITY.md](SECURITY.md). Сканер секретов не гарантирует обнаружение произвольного пароля.

Происхождение интерфейса, игровых данных, изображений и условия их распространения приведены в [NOTICE.md](NOTICE.md). Лицензия данных вики не распространяется автоматически на всю сборку и изображения, полученные непосредственно из игры.
